# fantasy-card-battle

A playable browser prototype of the fantasy card battle game inspired by Top Trumps.

## Overview
This project is a lightweight playable version of the concept described in the repo:
- 2-player gameplay against AI
- Fantasy themed cards
- Attributes: Age, Power, Speed, Height
- Deck-based card battles
- Round-by-round win logic

## How to run
Open `index.html` directly in a browser, or serve the folder locally:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Game structure
- `index.html` — page layout
- `styles.css` — game visuals
- `game.js` — game logic and card data

## Notes
The current version is a prototype and can be expanded to a larger card pool and richer animations, networking, or a full Unreal Engine 5.8 version later.
